# Customer Profile Builder

Structured technical profile with versioned history.

## Features
- Multi-step intake form
- AI-generated structured profile (services, risks, actions)
- Versioned profile history per customer
- Markdown export

## Usage
```bash
docker-compose up
```
- UI: http://localhost:8504
- API: http://localhost:8004
- API Docs: http://localhost:8004/docs
