# Interview Fit Agent

Resume + job description analysis with interview prep.

## Features
- PDF resume upload
- Fit grade A-F
- Strengths and gaps analysis
- 10 interview Q&A pairs
- Study plan
- Markdown export

## Usage
```bash
docker-compose up
```
- UI: http://localhost:8505
- API: http://localhost:8005
- API Docs: http://localhost:8005/docs
