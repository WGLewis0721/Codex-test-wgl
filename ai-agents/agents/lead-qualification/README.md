# Lead Qualification Agent

Deterministic scoring + AI explanation for sales leads.

## Features
- Wizard-style form with rubric scoring
- Score breakdown (budget, timeline, industry, use case)
- AI-generated explanation and follow-up email
- Score is deterministic (LLM cannot change it)

## Usage
```bash
docker-compose up
```
- UI: http://localhost:8503
- API: http://localhost:8003
- API Docs: http://localhost:8003/docs
